# Hackforge - Lawyer Matching Platform for Kerala

A modern, responsive React application to connect users with legal professionals in Kerala.

## Setup & Installation

1. Navigate to the Hackforge directory:
```bash
cd Hackforge
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will open automatically at `http://localhost:5173`

## Build for Production

```bash
npm run build
```

## Technology Stack

- React 18
- Vite
- React Router DOM
- Tailwind CSS

## Features

- Responsive design (Mobile + Desktop)
- Form validation with error handling
- localStorage integration
- Modern gradient UI
- Accessibility best practices
